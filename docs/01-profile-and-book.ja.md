### 本書の狙い（公式ページより）

対象は「コードを書くことが本業ではないビジネスパーソン」。「便利なのは分かったけれど具体的に何ができるのか」「セキュリティ面は大丈夫か」「会社に導入を認めてもらえない場合はどうするか」に答える構成。本書の「3つの強み」は、①何でもAIに相談する癖がつく、②「半自動化」のサイクルをつくれる、③モノレポで「コンテキストの複利」を生かせる。ゴールは「使うほど育つ」自分専用のAI秘書を手に入れること。

### 目次

- 第1章 なぜコーディングエージェントが日常業務に有用なのか
- 第2章 AIエージェントの基礎知識（料金プランとトークン消費、セキュリティの基本を含む）
- 第3章 Claude Codeのセットアップと基本操作（コネクタ、ブラウザー拡張機能の活用を含む）
- 第4章 何でもAIに相談する癖をつけよう（作業フォルダー作り、音声入力で自己紹介）
- 第5章資料作成の前工程を任せてみよう
- 第6章 「半自動化」のサイクルをつくろう（人間→AI→人間の流れ、ガードレール、手順ファイルを育てる）
- 第7章経費精算を半自動化してみよう
- 第8章 モノレポで「コンテキストの複利」を生かそう
- 第9章プロジェクト業務を「複利」で加速しよう
- 第10章 育った仕事場を4つの方向へ広げよう（仕様駆動開発、「生成AI臭さ」を消す、並行セッション、スマホからの指示、チーム資産化、他エージェントでの再利用）
- 第11章 企業における「セキュリティの壁」の乗り越え方

### 書評まとめ（note）

著者本人が書評ブログ11件をまとめた記事：https://note.com/minorun365/n/n097d72bd262b（2026-09-25、更新 2026-10-31）。末尾に書籍サポートページ（刊行後の仕様変更・つまずきポイントの補足）への案内がある。

書評で繰り返し言及されるポイント：

- **「半自動化」**（全自動を目指さず人間が要所で承認する進め方）が最多言及
- 日常業務を1リポジトリに集約する「モノレポ」運用
- Claude Code 専用の話ではなく、Codex／Kiro／Copilot ユーザーにも転用できる汎用性
- 「使うほど育つ／手元で育てる」AI秘書という捉え方
- 目次がツール機能からでなく「自分の仕事でやりたいこと」から組まれている構成
